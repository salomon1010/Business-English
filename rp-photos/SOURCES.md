# rp-photos — source and licence record

**STATUS: INCOMPLETE. Only the owner can finish this.**

Every file here was stripped of metadata before it was committed — no EXIF, no
XMP, no C2PA — so nothing in this repository can say where any of them came
from. That was checked, file by file, not assumed. The one file that still
carries an `Exif` byte sequence (`maya.jpg`) turned out to be a false positive:
the bytes are JPEG Huffman tables, not tags.

## Why this matters

`README.txt` in this folder already states the rule: *"only use images you may
redistribute commercially. Unsplash and Pexels licences allow this; Google
Images does not. Play Store removals for image licensing are common, so keep a
note of the source for each file."* That note was never kept. These images ship
inside a published Play app, so the exposure is real rather than theoretical.

It is also why Google Play's **AI-generated asset declaration** cannot be
answered from this repository: whether any of these were generated is a fact
about how they were obtained, and that fact exists nowhere here.

## What you have to do

Fill the two empty columns below. The `First committed` date is the lever —
these arrived in exactly two batches, so you are looking at your browser history
for two days, not for a month:

- **2026-07-31** — 14 files
- **2026-08-08** — 5 files

For each row, put the page URL you took the image from and the licence it was
released under. If it was generated by a tool, say which tool — that is the
answer Play needs, and "generated" is not a problem as long as it is declared.

If you cannot establish a source for a file, **replace it** rather than guess.
Unsplash and Pexels both allow commercial redistribution and both give you a
stable URL to record here.
