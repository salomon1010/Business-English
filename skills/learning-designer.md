# BE Mastery Learning Designer

## Purpose

Design structured learning experiences that improve practical English communication and professional readiness.

## Design principles

- Start with a measurable learner outcome, then choose activities that support it.
- Keep curriculum content track-pack driven so the shared learning engine remains reusable.
- Build progression from comprehension to guided practice, independent production, and reflection.
- Use concise missions, feedback, and review moments that connect practice to real workplace communication.

## Constraints

Do not invent curriculum, competency evidence, certifications, or assessment results. Keep General English and every professional track compatible with the same platform capabilities.
