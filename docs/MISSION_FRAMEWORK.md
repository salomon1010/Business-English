# Mission Framework

## Purpose

A Mission is the reusable learning unit that connects professional context to observable communication practice. It is the common experience model for General English and all professional tracks.

## Mission Journey

```text
Mission → Conversation → Vocabulary → Shadow → Phrase Lab → Coach → Evidence → Next Mission
```

The exact order may vary when the mission has a good instructional reason, but every mission declares why each step exists and what evidence it can create.

## Mission Contract

| Field | Description |
|---|---|
| Identity | Track, stage/week, mission ID, title, estimated effort |
| Professional outcome | The workplace communication capability the learner is practising |
| Scenario | Context, character(s), and realistic communication boundary |
| Objectives | 2–4 observable communication objectives |
| Prerequisites | Previously completed or recommended mission evidence |
| Steps | Conversation, Vocabulary, Shadow, Phrase Lab, focused practice in a deliberate sequence |
| Target language | Track-owned words, phrases, and pronunciation focus |
| Evidence plan | What counts as participation, production, and demonstration |
| Coach contract | Allowed evidence inputs and one next-action rule |
| Competency mapping | Configuration-owned mappings; never implied from a label alone |
| Completion and milestone | Completion rule, achievement eligibility, and next-mission criteria |

## Learning Sequence

1. **Briefing** — Explain the workplace moment, outcome, and one first action.
2. **Conversation** — Practise a one-to-one workplace exchange with the assigned character.
3. **Vocabulary** — Meet only the terms needed to understand or produce the mission language.
4. **Shadow** — Hear and repeat a relevant delivery model.
5. **Phrase Lab** — Rehearse a small number of adaptable phrases.
6. **Coach** — Reflect on actual evidence, name one strength and one next practice choice.
7. **Evidence** — Separate completed work from recorded/transcribed production and objective demonstration.
8. **Next Mission** — Explain the professional connection and recommend a single next step.

## Evidence Rules

| State | Permitted claim |
|---|---|
| No usable evidence | “No assessment yet; record or complete the next step.” |
| Participation | “You completed this mission step.” |
| Production | “You produced a response for review.” |
| Demonstration | “Your response addressed this stated objective.” |
| Growth | “Comparable evidence shows this specified change.” |

No score, competency award, achievement, or readiness statement may be created solely by opening a mission, viewing material, or ending an empty conversation.

## Mission Types

- **Foundation mission:** professional identity, introductions, clarification, workplace language.
- **Team mission:** handover, coordination, briefing, colleague communication.
- **Safety/quality communication mission:** observe, clarify, escalate, and report without operational claims.
- **Career mission:** interview, experience story, destination preparation, professional profile.

## Track Implementation Boundary

Mission definitions belong in track curriculum data. The existing Curriculum Provider, Professional Track Context, Competency Engine, Learning Coach, Adaptive Learning Engine, Professional Simulation Engine, Skills Passport, and Career Center remain shared services. A future profession adds content/configuration, reviewed vocabulary, characters, mission objectives, and evidence mappings—not new application logic.

## General English Mapping

General English week/day content becomes a mission presentation layer: existing sessions retain their content and completion behavior while gaining a clear outcome, targeted supporting activities, evidence language, and next mission. It does not become a fake professional track.
