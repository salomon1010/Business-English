# Curriculum Architect

Use when evolving track curriculum packs or mapping content to the shared learning engine.

## Design principles

- Store track-specific learning content in the track pack rather than hard-coding it into screens.
- Preserve compatible schemas for Weeks, Shadow, Phrase Lab, Vocabulary, Practice, Progress, mentors, and simulations.
- Build professional progression as workplace capability, not disconnected language lessons.
- Keep future-track packs usable without cloning application code.

## Workflow

1. Identify the professional stage and its learner outcome.
2. Add only content supported by the current provider and learning engines.
3. Map objectives to available activities and competency configuration.
4. Add safe placeholders rather than inventing curriculum or assessment evidence.
5. Verify track switching changes content only and does not change shared layouts.
